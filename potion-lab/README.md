#magic_cauldron_card_generator
# โรงปรุงยาใต้แสงจันทร์ (Potion Lab)

เว็บปรุงยาวิเศษสำหรับงาน Open House ITAI DPU

## โครงสร้างไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | โครงหน้าเว็บ (ปุ่ม กล่อง ข้อความต่างๆ) |
| `css/style.css` | หน้าตา สี ฟอนต์ แอนิเมชัน |
| `css/background.css` | ภาพพื้นหลังสุสานม่วง (ฝังเป็นข้อมูลรูป ไม่ต้องแก้) |
| `js/app.js` | การทำงานทั้งหมด: ข้อมูลยา สูตรลับ คำท้า ลากวาง เสียง การ์ด คำสั่ง Gemini |
| `qr-poster.html` | หน้าสร้างโปสเตอร์ QR |

## วิธีเปิด

- **ดูอย่างเดียว:** ดับเบิลคลิก `index.html`
- **แก้โค้ด:** เปิดโฟลเดอร์นี้ใน VS Code แล้วคลิกขวา `index.html` → Open with Live Server

## จุดที่แก้บ่อย (ค้นหาใน `js/app.js` ด้วย Ctrl+F)

- `const potionsData` ชื่อยา คำอธิบาย ความชอบ เส้นทาง ภารกิจ
- `const LORE` ชื่อพลัง สีประจำยา หน้าตาผีน้อยในคำสั่ง Gemini
- `const CHALLENGES` คำท้าภารกิจทดลอง 3 หมวด
- `const LEGENDS` สูตรลับในตำนาน 6 สูตร
- `const QUIZ` คำถามโหมดให้แม่มดช่วยทายใจ
- `const PATH_INFO` คำอธิบายเส้นทางอาชีพ
- `$('prompt').value =` ข้อความคำสั่งที่คัดลอกไปใช้ใน Gemini
